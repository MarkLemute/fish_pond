# Fish Pond

A koi pond game built with Python and Pygame.

Swim your koi around the pond, eat food pellets to grow, and keep your hunger bar from running out. Rival fish compete for the same food, and golden pellets are worth extra. Grow big enough to clear the level and move on through 10 different ponds, from a garden pond to a desert oasis. Your high score and furthest level are saved.

## How to play

```bash
pip install -r requirements.txt
python fish_pond.py
```

## Controls

| Key | Action |
| --- | --- |
| Arrow keys / WASD | Swim |
| Space | Start / next level / retry |
| C | Continue from your furthest level (menu) |
| P | Pause |
| M | Back to menu (game over) |
| Esc | Quit |
